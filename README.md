# Тестовый лендинг Hermes

Этот репозиторий содержит тестовый лендинг, развёрнутый через GitHub Pages.

## Файлы

- `index.html` — главная страница лендинга
- `_config.yml` — конфигурация Jekyll (опционально, для GitHub Pages)

## Деплой

Публикуется автоматически через GitHub Pages из ветки `main`.
